Report Sync · Privacy

Report Sync usa solo l'autorizzazione Google drive.file: crea e aggiorna i propri file nel Google Drive dell'utente che l'ha autorizzata e non accede ad altri file o dati dell'account. I dati ottenuti dalle API di Google non sono ceduti a terzi né usati per altri scopi, nel rispetto della Google API Services User Data Policy (Limited Use). L'accesso si revoca da myaccount.google.com/permissions.

Report Sync uses only the Google drive.file scope: it creates and updates its own files in the authorizing user's Google Drive and accesses no other files or account data. Data obtained from Google APIs is not shared with third parties or used for any other purpose, in compliance with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
